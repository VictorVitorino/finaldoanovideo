# Alerta

Nota de contexto ou estado com faixa lateral colorida e texto navy sobre `surface-subtle`.

- `.am-alert` + `-info` (azul), `-positive`, `-attention`, `-negative`.
- A cor fica só na faixa de 6px; o texto permanece `ink` para manter contraste.
- Estrutura: `<div class="am-alert am-alert-…"><div><strong>Título</strong><p>Texto</p></div></div>`.
- Título afirma o fato; o texto dá o número que o sustenta.
